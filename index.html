Microsoft Loop und Datensicherheit

Diese App funktioniert auf Computer und Handy im Browser. Die Daten werden lokal auf dem jeweiligen Gerät gespeichert. Über „Synchronisieren“ kannst du abgeschlossene Einträge mit deinem persönlichen OneDrive abgleichen. Loop kann den App-Link öffnen.

Für den Gerätewechsel: Einheit auf Gerät A abschließen und „Synchronisieren“ wählen. Danach auf Gerät B mit demselben Microsoft-Konto anmelden und ebenfalls synchronisieren. Alternativ: „Sicherung (JSON)“ exportieren und auf dem anderen Gerät importieren. Beim Import werden Einträge anhand ihrer ID zusammengeführt; laufende Timer werden nicht synchronisiert. Arbeite daher möglichst immer nur auf einem Gerät gleichzeitig.

Um die App aus Microsoft Loop zu öffnen, muss diese HTML-Datei als Website über eine HTTPS-Adresse veröffentlicht werden. Anschließend kannst du den Link auf deiner Loop-Seite einfügen. Ein normaler OneDrive-Dateilink führt nicht zuverlässig eine HTML-App aus.

Microsoft-Anmeldung, Verbindungstest und Synchronisieren benötigen Internet. Keine automatische Cloud-Sicherung. Private Browserfenster, gelöschte Browserdaten oder ein anderer Browser können die lokalen Einträge unzugänglich machen. Regelmäßig JSON-Sicherungen erstellen. Für verbindliche Lohnabrechnung Einträge prüfen.
